# مستودع الأرباح — مشروع Capacitor

## الخطوات من الجوال (بدون كمبيوتر)

### 1) إنشاء مستودع على GitHub
- افتح github.com من متصفح الجوال، سجّل دخول أو أنشئ حساب
- اضغط "+" → "New repository" → سمّه (مثلاً warehouse-tycoon-app) → Create

### 2) رفع هذا المجلد
ارفع كل الملفات اللي بهذا المجلد (بما فيها مجلد .github المخفي) لنفس المستودع.
أسهل طريقة من الجوال: استخدم تطبيق GitHub الرسمي (Android/iOS) أو موقع github.dev
(افتح رابط المستودع وبدّل .com بـ .dev بالرابط يفتحلك محرر كامل بالمتصفح تقدر تسحب وتفلت الملفات فيه).

### 3) البناء التلقائي
أول ما ترفع الملفات لفرع main، GitHub Actions راح يشتغل تلقائياً ويبني APK.
تابع التقدم من تبويب "Actions" بأعلى صفحة المستودع.

### 4) تحميل APK
بعد ما يخلص البناء (يأخذ 3-6 دقايق تقريباً)، روح لتبويب Actions → اضغط آخر تشغيل ناجح
(علامة ✓ خضراء) → تحت "Artifacts" بتلقى "warehouse-tycoon-debug-apk" → نزّله وثبّته على أي جهاز أندرويد.

## ملاحظات مهمة
- هذا APK "debug" (للتجربة فقط) — قبل النشر على Google Play لازم نبني نسخة "release" موقّعة بمفتاح خاص.
- تأكد تضيف نطاق تطبيقك (بعد ما يصير عندك) لقائمة "Authorized domains" بإعدادات Firebase Authentication.
